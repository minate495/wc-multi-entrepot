Ceci est un plugin qui répond au besoins de société ou entreprises disposant de plusieurs entrepôt physique qui voudrait les lier à leurs site web.
Vous avez la possibilité de créer autant d'entrepôt possible, le plugin n'empêche en aucun cas le fonctionnement native de Woocommerce, il ajoute juste des fonctionnalité comme :
La déduction de stock par entrepôt
Le réapprovisionnement automatique d'un entrepôt à un autre
